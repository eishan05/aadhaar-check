Aadhaar Number Checker

Check whether an Aadhaar number or 16-digit Virtual ID is correctly formed and free of typing mistakes. The check runs on your device. Nothing you type leaves this page.

Type or paste a number to check it.

Spaces and hyphens are fine. Digits typed in Hindi, Punjabi, Tamil and other Indian scripts work too.

    Show the checksum calculation

    Verhoeff's method reads the digits from right to left. Each digit is first scrambled by a permutation p that depends on its position i, then combined into a running value c using the multiplication table d of the dihedral group D5. The number is valid only if c ends at 0.

    i (from right)Digitp(i mod 8, digit)c = d(c, p)

    What is checked

    1. Digits only. Spaces and hyphens are ignored. Letters and other symbols are flagged.
    2. Exactly 12 digits for an Aadhaar number (16 for a Virtual ID).
    3. First digit is 2 to 9. UIDAI reserved a leading 0 for future longer numbers and a leading 1 for entity IDs, so no resident's Aadhaar number starts with either.
    4. Verhoeff check digit. The last digit is computed from the other eleven. The scheme catches every single mistyped digit and every swap of two neighbouring digits. If the check fails, the page lists the numbers you may have meant.

    Source: UIDAI, A UID Numbering Scheme (May 2010), which specifies the 12-digit format, the reserved first digits and the Verhoeff check digit. UIDAI's Virtual ID circular (2018) specifies the 16-digit VID with the same check digit.

    What a pass means, and what it doesn't

    A pass means the number is correctly formed: it has no single-digit typo and no swapped neighbouring digits. It does not mean the number was ever issued, is still active, or belongs to a particular person. About one in ten random 12-digit strings starting with 2 to 9 passes the check. Only UIDAI can confirm that a number exists, through its official Check Aadhaar Validity service.

    Private by construction. Check it yourself.

    This page is three small files you can read in a few minutes: index.html, aadhaar.js (the checks) and app.js (the page). Nothing else loads: no analytics, fonts, trackers or third-party code.

    • The browser enforces it. The page carries a Content Security Policy with connect-src 'none' and default-src 'none'. Your browser refuses any attempt by this page to send data, whatever the code says.
    • Watch the network. Open your browser's developer tools (F12), go to the Network tab, and type a number. No requests appear.
    • Go offline. Load the page, turn on airplane mode or disconnect, and keep checking numbers. It works the same.
    • Nothing is kept. No cookies, no local storage, and the number never goes into the address bar or your history. Spell-check and autofill are switched off on the input, so the browser doesn't send it to a spelling service either.
    • Run your own copy. Download the repository and open index.html, or serve it with any static file server.

    GitHub Pages, which hosts these files, sees your IP address when you load the page, as any web host does. It never sees what you type. Browser extensions you have installed can read every page you visit, this one included. If that worries you, use a private window with extensions off.
